# 0010 — Target user and naming

**Status:** Accepted

## Decision
The primary user is an early-career job seeker in India, on- or off-campus: many concurrent processes, OA-heavy funnels, multiple interview rounds, tight deadlines. Default locale stays `en-IN`.

"Job Drive" stays as the core term because it is native to this audience. Copy should still read clearly to anyone else ("a hiring process for one company and role").

## Consequences
- Interview rounds become a visible list (R1, R2, HR) instead of one consolidated phase.
- The home screen becomes an agenda: upcoming OA deadlines, interviews, apply-by dates, and drives with no update in 21 days (a computed "stale" flag, not a stage).
- The composer accepts pasted OA invitations, recruiter emails, and calendar text as its main AI use case.
